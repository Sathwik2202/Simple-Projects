 Project Overview:
   This project demonstrates Image Compression using Singular Value Decomposition (SVD). By decomposing an image matrix into its constituent parts, we can retain only the most significant singular values to reconstruct the image with significantly less data, illustrating the power of energy compaction in linear algebra.
   
🛠️ Tech Stack
Language: Python
Libraries: NumPy, Matplotlib
Environment: Google Colab

🚀 Key Concepts
Singular Value Decomposition (SVD): Decomposing the image into $U$, $\Sigma$, and $V^T$ matrices.
Compression Ratio: Comparing the original file size against the truncated version.
